# FortniteCNManifestArchive

A collection of all known manifests from the chinese regional version of fortnite. Despite the game's shutdown, manifests and their chunks remain live on the qq cdn.

Notes:

- The 'CertHK' builds are all cert tree versions with content between version 2.2.0 - 2.3.0
- The majority of these builds are not playable at all without swapping their FortniteClient-Win64-Shipping.exe with the international counterpart due to tenprotect anti-cheat measures in place. Two known exceptions are **3.5-CL-4003920-CN** & **4.0-CL-4039451-CN** due to the fact that they ship a FortniteClient.exe file which contains additional debug symbols, console enabled, and lacks tenprotect.
- Some builds have a direct download option thanks to community re-uploads. Most also have a working official installer. Some builds are only available via manifest/.7z chunks, to install these builds and for faster downloads in general, see [Ripple Installer](#Ripple)

## Ripple

A simple cli installer tool for wegame manifests. Inspired by [splash](https://github.com/polynite/splash) & [EasyInstaller](https://github.com/Kyiro/Fortnite-ManifestsArchive)

### Examples

Download from local manifest into current working directory (ie. from where the command was ran)

```sh
./ripple.exe "C:/Users/Nick/Downloads/fncn_manifests/100_verify.json"
```

Download into a different parent directory

```sh
./ripple.exe --out "C:/Program Files/FNCN"
```

Download from a remote manifest

```sh
./ripple.exe --remote-manifest "https://down.qq.com/tgc/tgp/rail/2000196/1/185/8006ea6c39dd60e60628790dc2f30185/whole/2000196_1_0.0.0.185_verify.json"
```

Download using a different qq cdn mirror or archive mirror

```sh
./ripple.exe --host {wgdl.qq.com|dlied1.qq.com|down.qq.com}
```

Download contents directly into output root instead of wrapping in a folder

```sh
./ripple.exe --no-wrap
```

### Wrapper Folder

By default files will be extracted into a new folder placed in the specified output root. If the install is done via the TUI, this folder will use the fortnite version string (ie. `3.3-CL-3956103-CN`). If the install is done via directly passing the manifest file/url to the cli, this context will not be available and the folder will use the wegame depot name (ie. `RailGame_2000196_1-0.0.0.49`).
